# Реальные отзывы SKU для Ozon

Расширение для Microsoft Edge (подходит и для Chrome), которое показывает в выдаче ozon.ru, сколько отзывов у **конкретного варианта товара**, а не у всей группы.

## Зачем

Ozon объединяет варианты товара (длина кабеля, число розеток, размер, цвет) в группу и на каждой карточке выдачи пишет общее число отзывов группы. Фильтр с 315 отзывами выглядит как хит с 16 873, и у нескольких разных вариантов в выдаче стоит одно и то же число.

Расширение меняет подпись на карточке:

```
16 873 отзыва   →   315 из 16 873
```

![Скриншот](docs/images/screenshot.png)

### Переключатели

В левой панели фильтров, над «Распродажей», появляются два переключателя:

- **Реальные отзывы** — подписи «315 из 16 873» вместо общего числа (по умолчанию включено).
- **Сортировать по отзывам** — показывает выдачу, отсортированную по реальному числу отзывов варианта (по умолчанию выключено).

Положение переключателей запоминается.

### Сортировка по реальным отзывам

Ozon не умеет сортировать по отзывам варианта, поэтому расширение собирает первую страницу выдачи (24 товара) через API сайта и показывает свой список вместо сетки Ozon. Карточки повторяют карточки Ozon: галерея, цена, «В корзину» со счётчиком «− 1 +», избранное.

- Пока собираются отзывы, в заголовке виден прогресс: «Собираю отзывы 12 / 24…».
- Порядок фиксируется один раз и сам не меняется — карточки не прыгают, пока вы их смотрите.
- **«Загрузить ещё»** добавляет следующие 24 товара в конец списка.
- Если новые данные меняют порядок, внизу появляется кнопка **«Пересортировать (+N)»** — порядок обновится только по нажатию.

Выключите переключатель — вернётся обычная выдача Ozon.

## Установка

1. Скачайте `ozon-sku-reviews-<версия>.zip` со страницы [Releases](../../releases) и распакуйте.
2. Откройте `edge://extensions` (в Chrome — `chrome://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное» и выберите распакованную папку.

## Сборка из исходников

Нужен Node.js 24+.

```bash
npm ci
npm run build   # собирает расширение в dist/
npm test        # юнит-тесты
npm run zip     # упаковывает dist/ в zip
```

Затем загрузите папку `dist/` через «Загрузить распакованное».

## Как это работает

Для каждой карточки расширение делает тот же запрос, что и сайт Ozon на вкладке отзывов: `/product/<SKU>/reviews/pdp-part`. Число берётся из переключателя «Этот вариант товара (N)». Запросы идут медленно (не больше 2 одновременно, с паузой), видимые карточки — первыми. Результаты кэшируются в браузере на 6 часов. Если Ozon начинает ограничивать запросы, расширение сразу останавливается и пишет об этом под переключателями.

Для сортировки выдача загружается тем же запросом, которым её подгружает сам сайт. Корзина и избранное в отсортированном списке используют те же запросы, что и кнопки Ozon.

## Ограничения

- Расширение неофициальное и опирается на внутренний API Ozon. Если Ozon его изменит, подписи перестанут появляться до обновления расширения.
- Рейтинг (звёзды) остаётся групповым: Ozon не отдаёт рейтинг отдельного варианта.
- Если у товара нет вариантов, подпись не меняется: число отзывов и так его собственное.
- Сортировка охватывает только собранные товары (по 24 за раз), а не всю выдачу.
- После действий в отсортированном списке счётчики корзины и избранного в шапке обновляет расширение; полностью Ozon синхронизирует их после перезагрузки страницы.
- Частые сборы выдачи (много запросов подряд) могут вызвать у Ozon проверку «я не робот».

## Приватность

Расширение ничего не собирает и никуда не отправляет. Запросы уходят только на ozon.ru от вашего имени, как при обычном просмотре сайта. Кэш хранится локально в браузере.
